./HTTP_SERVER_REQUIRED

Modern web browsers restrict JavaScript modules (<script type="module">) from executing over the local file:// protocol due to browser CORS security policies.

To view this build locally, run a lightweight HTTP server: 

npm run preview
# or
npx serve dist
# or
python3 -m http.server 3000 --directory dist

When hosted on GitHub Pages or any web server over HTTP/HTTPS, the application initializes and renders automatically.
